## Overview
Movie Recommender Pro is a Netflix-style web app built using Vanilla JavaScript. It allows users to explore trending movies, search and filter content, and maintain a personal watchlist using real-world API data.

## Features
- Trending movies dashboard  
- Smart search with debouncing  
- Mood-based recommendations  
- Advanced filtering (genre, year, rating)  
- Watchlist management  
- Movie trailers and similar movie suggestions  
- Fully responsive UI  

## Tech Stack
- HTML5, CSS3, JavaScript (ES6+)  
- TMDb API  
- OMDb API  
- Browser Local Storage  

## Run Locally
This project uses ES6 modules and must be served via a local server.

python -m http.server

Open in browser:  
http://localhost:8000
